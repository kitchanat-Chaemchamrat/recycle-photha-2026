ระบบบริหารจัดการขยะชุมชน

นวัตกรรมเพื่อสิ่งแวดล้อมที่ยั่งยืน และการบริหารจัดการเงินปันผลอย่างเป็นธรรม

เริ่มใช้งานระบบ ดูคุณสมบัติหลัก

เกี่ยวกับระบบ

ระบบบริหารจัดการขยะชุมชน (Community Waste Management System) ถูกพัฒนาขึ้นเพื่อยกระดับการจัดการขยะในระดับชุมชน โดยเน้นการคัดแยกขยะตั้งแต่ต้นทาง และสร้างแรงจูงใจด้วยระบบเงินปันผลที่โปร่งใส ตรวจสอบได้

ระบบช่วยให้คณะกรรมการชุมชนสามารถติดตามปริมาณขยะ ประเมินผลการคัดแยกของแต่ละครัวเรือน และบริหารจัดการรายได้จากการขายขยะรีไซเคิลกลับคืนสู่สมาชิกได้อย่างมีประสิทธิภาพ

ระบบรองรับ QR Code

สแกนเพื่อเข้าถึงข้อมูลรายบ้านและบันทึกคะแนนได้ทันที

คุณสมบัติเด่นของระบบ

Dashboard สรุปภาพรวม

แสดงข้อมูลสถิติสำคัญ เช่น ปริมาณขยะรวม รายได้ และคะแนนเฉลี่ยของชุมชนในรูปแบบกราฟที่ดูง่าย

ระบบประเมินผลอัจฉริยะ

บันทึกคะแนนการคัดแยกขยะรายบ้าน พร้อมแนบรูปถ่ายเป็นหลักฐานเพื่อความโปร่งใส

คำนวณเงินปันผลแม่นยำ

ระบบคำนวณส่วนแบ่งรายได้ให้สมาชิกโดยอัตโนมัติตามสัดส่วนคะแนนและปริมาณขยะ

รายงานและส่งออกข้อมูล

รองรับการส่งออกข้อมูลเป็น PDF และ Excel เพื่อสรุปผลรายเดือนหรือรายปี

สแกนผ่าน QR Code

เจ้าหน้าที่สามารถสแกน QR Code หน้าบ้านเพื่อบันทึกน้ำหนักและประเมินผลได้รวดเร็ว

ระบบจัดการสิทธิ์ผู้ใช้

แยกสิทธิ์การใช้งานชัดเจนสำหรับ ผู้ดูแลระบบ, คณะกรรมการ และเจ้าหน้าที่เก็บขยะ

ระดับการเข้าใช้งาน

บทบาท (Role) คำอธิบายสิทธิ์การใช้งาน
Super Admin เข้าถึงทุกฟังก์ชันในระบบ ตั้งค่าระบบพื้นฐาน และจัดการสมาชิกทั้งหมด
Admin จัดการข้อมูลบ้าน สมาชิก บันทึกการขายขยะ และคำนวณเงินปันผล
Collector บันทึกคะแนนการคัดแยก (ประเมิน) และบันทึกน้ำหนักขยะรายบ้าน
Auditor ดูรายงานภาพรวม และ Dashboard เพื่อตรวจสอบความโปร่งใส

เริ่มต้นใช้งานเบื้องต้น (Quick Start)

เข้าสู่ระบบ

ใช้บัญชีที่ได้รับจากผู้ดูแลระบบเพื่อเข้าสู่ระบบที่หน้า Login

บันทึกข้อมูลพื้นฐาน

เพิ่มข้อมูลซอย, บ้าน และสมาชิกในชุมชนให้ครบถ้วน

ประเมินผลและชั่งน้ำหนัก

เจ้าหน้าที่ลงพื้นที่บันทึกคะแนนและน้ำหนักขยะผ่านแท็บเล็ตหรือมือถือ

สรุปผลและปันผล

เมื่อสิ้นสุดรอบการขายขยะ ผู้ดูแลระบบทำการสรุปและออกเงินปันผล

ข้อมูลทางเทคนิค
  • เทคโนโลยี: PHP 8.0+, MySQL
  • การแสดงผล: รองรับ Mobile, Tablet และ Desktop (Responsive)
  • ความปลอดภัย: ระบบ Login แยกสิทธิ์ และการเข้ารหัสข้อมูล
  • ฐานข้อมูล: remon_waste
